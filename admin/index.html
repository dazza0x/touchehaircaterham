Decap CMS — One-Time Setup Required

The CMS backend needs a Cloudflare Worker for GitHub OAuth. Follow these steps once, then update admin/config.yml with your Worker URL.

  1. Create a GitHub OAuth App
    Go to github.com/settings/developers → New OAuth App.
    Homepage URL: https://www.touchehaircaterham.com
    Callback URL: https://YOUR-WORKER.workers.dev/callback (fill in after step 2).
  2. Deploy the sveltia-cms-auth Cloudflare Worker
    Follow the README at github.com/sveltia/sveltia-cms-auth.
    Set environment variables: GITHUB_CLIENT_ID, GITHUB_CLIENT_SECRET, ALLOWED_DOMAINS=touchehaircaterham.com.
  3. Update admin/config.yml
    Replace REPLACE-WITH-YOUR-WORKER-URL with your deployed Worker URL (e.g. https://touche-cms-auth.yourname.workers.dev).
  4. Push to GitHub
    Commit and push admin/config.yml. Reload this page — the CMS login will appear.
